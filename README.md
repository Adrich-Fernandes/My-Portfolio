# Personal Portfolio Website

A responsive personal portfolio website built with **HTML, CSS, and JavaScript** to showcase my profile, skills, projects, tools, and contact information. The site features smooth scrolling, animated UI elements, a mobile-friendly navigation menu, and a modern dark-themed design.

---

## 🚀 Features

* **Responsive Design** – Works across desktop, tablet, and mobile screens
* **Mobile Navigation Menu** – Toggle-based menu for smaller screens
* **Smooth Scrolling** – Clean navigation experience
* **Animated UI Elements** – Hover effects, transitions, and gradients
* **Skills Section** – Visual representation using icons
* **Projects Section** – Showcases mini projects with GitHub links
* **Contact Section** – Contact details and a simple message form
* **Scroll-to-Top Button** – Quick navigation back to the top

---

## 🛠️ Tech Stack

* **HTML5** – Structure and semantic layout
* **CSS3** – Styling, animations, responsive design
* **JavaScript (Vanilla)** – Interactivity and DOM manipulation
* **Font Awesome** – Icons for skills and social links
